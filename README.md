# 照樣造句學習單產生器（低年級）

給家長和老師**列印**用的照樣造句學習單。選好年級、題數、書寫格和插圖樣式，按「列印」就能印出 A4 學習單，不是線上作答工具。

- 一年級：完整句（誰＋做什麼、誰＋是＋什麼⋯）
- 二年級：四要素句（時間＋人物＋地點＋事情）
- 三年級：說清楚說生動（一邊⋯一邊⋯、因為⋯所以⋯、形容詞、心情、先⋯再⋯）

每題包含「讀一讀，找一找」「照樣寫」「寫我的生活」三段，可附家長／老師引導小抄。

出題方式有兩種：

- **課表模式**（一年級）：選「第 N 次」，依固定順序印出該次的全部題目（每次 3 題）。
- **隨機模式**：從該年級題庫隨機抽 3～5 題，可按「重新抽題」。二、三年級目前只有隨機模式。

## 使用方式

- 線上：開啟 GitHub Pages 網址即可。
- 離線：下載整個資料夾，直接雙擊 `index.html`，不需要安裝任何東西。
- 列印時請在瀏覽器列印設定選 A4、邊界「無」、勾選「背景圖形」。

畫面上方有兩個提示：

- **注音字型**：顯示「已載入」才代表注音字型生效，印出來才會有注音。
- **版面**：顯示「OK」代表每頁都沒有超出 A4；若顯示「第 N 頁超出 A4」，可改用其他書寫格設定或重新抽題。

一年級預設使用「注音格」，二、三年級預設「國字格」。一年級若改選「國字格＋旁附注音欄」，故事較長的題目會超出 A4。

## 檔案結構

```
index.html          頁面骨架與控制面板
css/style.css       畫面與學習單版面（含 @font-face）
css/print.css       列印設定（A4、分頁）
js/svgs.js          插圖繪製函式與所有 SVG 插圖
js/app.js           產生學習單、抽題、版面與字型檢查
data/grade1.js      一年級題庫
data/grade2.js      二年級題庫
data/grade3.js      三年級題庫
fonts/              字嗨注音標楷字型檔與原始授權檔
legacy/             原始單一檔案版本（保留比對用）
```

題庫用「全域變數＋`<script>` 標籤」載入，所以不需要伺服器或建置工具。

## 如何新增題目

打開對應年級的 `data/gradeN.js`，在 `stories: [ ... ]` 裡照既有格式加一題：

```js
{ title:'題目名稱', pattern:'誰＋做什麼', svg:'park',
  text:['第一句。','第二句。'],                 // 故事，每句一個字串
  find:'用○圈出「誰」，在「做什麼」下面畫線。',
  example:[['哥哥','誰'],['寫功課','做什麼'],['。','標點']], // 範例積木：[文字, 標籤]
  fill:{given:'阿公', ans:3, hint:'阿公在故事裡做什麼？'},   // given＝預先印好的字，ans＝預估要寫幾個字
  life:'昨天晚上，你做什麼事？', lifeEst:12 },  // lifeEst＝寫我的生活預估字數（含標點）
```

- `svg` 填 `js/svgs.js` 裡 `SVGS` 已有的插圖名稱：`breakfast`、`family`、`bag`、`park`、`hide`、`night`、`library`、`market`、`lunch`、`brush`。
- `lesson:N`（選填）：課表第幾次。一年級目前每次 3 題，題目在檔案裡的順序就是列印順序。只要某個年級有題目帶 `lesson`，控制面板就會出現「出題方式：課表／隨機」；課表模式只會列出資料裡實際存在的次數。
- 三年級可另加 `plan:[...]`（先想一想構思框標題）與 `subq:'...'`（寫我的生活的說明）。
- 題數下拉選單最多 5 題，每個年級至少要有 5 題。
- 存檔一律用 **UTF-8**。
- 新增後重新整理頁面，多按幾次「重新抽題」，確認版面提示是 OK。

## 如何校對注音（破音字）

字嗨注音標楷用 **IVS 異體字選擇器**（Unicode U+E0100–U+E01EF，看不見的字元）來指定破音字的讀音。

1. 把要校對的句子貼到 bpmfvs 的線上工具：<https://buttaiwan.github.io/bpmfvs/>
2. 在工具裡把讀錯的字切換成正確讀音。
3. 複製修正後的文字，貼回題庫檔中引號 `'...'` 內，覆蓋原本的文字。
4. 以 **UTF-8** 存檔。

注意事項：

- IVS 字元看不見，但會跟著字一起被複製；不要用會「清除特殊字元」的編輯器或工具處理題庫檔。
- 程式會把 IVS 字元和前一個字合併成同一格（`splitChars`），所以預先印好的字（`given`）也可以含 IVS。
- 確認方式：在網頁上看該字的注音是否已改成正確讀音。

## 字型

使用 [字嗨注音標楷（BpmfZihiKaiStd）](https://github.com/ButTaiwan/bpmfvs)，版本 v1.500，作者 But Ko。

字型檔放在 `fonts/`，是**完整、未修改**的原始檔（約 17 MB，含 cmap format 14 注音切換表）。沒有縮減字型的原因：

- 縮檔後的字型屬於 OFL 定義的「修改版」，依授權不得再使用保留字型名稱「字嗨」「Zihi」。
- 縮檔可能破壞注音切換功能（cmap format 14）。
